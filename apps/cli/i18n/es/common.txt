# Mensajes de `raptor` para el usuario, en español (NFR-10, ADR-GRP-003): common.
# Una línea `clave = texto`. Los marcadores son `{nombre}`; el código los
# rellena por nombre, nunca concatenando. Toda clave existe también en ../en/common.txt.

common.not-running = no está en marcha
common.cancelled = cancelado
common.confirm-needs-terminal = la confirmación necesita una terminal (o usa --yes)
common.refused-terminal = rechazado: ejecútalo desde tu propia terminal
common.refused-terminal-no-console = rechazado: este proceso no tiene consola; ejecútalo desde una ventana de consola (PowerShell, cmd o Windows Terminal)
common.refused-terminal-session = rechazado: no desde una sesión SSH ni desde un servicio (sesión 0); ejecútalo desde una consola local o de Escritorio remoto
common.refused-terminal-foreign-console = rechazado: esta consola no la abrió tu shell (otro proceso se unió a ella); ejecútalo desde una consola que hayas abierto tú
common.refused-unverified = rechazado: el motor no pudo verificar quién lo pide
common.refused-unverified-console = rechazado: los comandos reservados solo se aceptan desde una consola interactiva (PowerShell, cmd o Windows Terminal); esta terminal no permite al motor verificar quién los pide
common.refused-unverified-terminal = rechazado: los comandos reservados solo se aceptan desde una terminal interactiva; esta no permite al motor verificar quién los pide
