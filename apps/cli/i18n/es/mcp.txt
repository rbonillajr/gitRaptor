# Una línea `clave = texto`. Los marcadores son `{nombre}`; el código los
# rellena por nombre, nunca concatenando. Toda clave existe también en ../en/mcp.txt.

mcp.agent-unsupported = {agent} no está soportado todavía; usa --agent claude-code
mcp.not-installed = rechazado: GitRaptor se está ejecutando desde {path}, una carpeta temporal o una caché de npx; instala GitRaptor primero y ejecuta raptor mcp install desde la copia instalada
mcp.server-missing = rechazado: no se encontró raptor-mcp en {path}; reinstala GitRaptor
mcp.server-unsafe = rechazado: otros usuarios pueden modificar {path}; corrige sus permisos o reinstala GitRaptor
mcp.claude-missing = no se encontró la CLI de Claude Code; no se cambió nada. Registra el servidor tú mismo con:
mcp.claude-changed = rechazado: la CLI de Claude Code respondió de una forma que este GitRaptor no conoce; no se cambió nada. Actualiza GitRaptor o ejecuta tú este comando:
mcp.claude-failed = la CLI de Claude Code falló (código {code}); GitRaptor no cambió nada más
mcp.foreign = rechazado: ya existe en Claude Code un servidor gitraptor que no es de este GitRaptor; retíralo con claude mcp remove gitraptor y vuelve a instalar
mcp.foreign-uninstall = rechazado: el servidor gitraptor de Claude Code no es de este GitRaptor; retíralo con claude mcp remove gitraptor si quieres quitarlo
mcp.install.plan = Registrando el servidor MCP gitraptor en Claude Code para todos los proyectos (ámbito de usuario); tus otros servidores MCP y tus repos no cambian. Se ejecuta:
mcp.install.done = gitraptor registrado en Claude Code (ámbito de usuario) → {path}
mcp.install.already = gitraptor ya está instalado en Claude Code; nada que hacer
mcp.uninstall.plan = Retirando el servidor MCP gitraptor de Claude Code (ámbito de usuario); tus otros servidores MCP no cambian. Se ejecuta:
mcp.uninstall.done = gitraptor retirado de Claude Code
mcp.uninstall.absent = gitraptor no está instalado en Claude Code; nada que hacer
mcp.enabled = los agentes ya pueden usar {path} por el MCP
mcp.already-enabled = {path} ya estaba habilitado para el MCP; nada que hacer
mcp.disabled = los agentes ya no pueden usar {path} por el MCP; sigue observado
mcp.already-disabled = {path} no estaba habilitado para el MCP; nada que hacer
mcp.observe-first = rechazado: {path} no es un repo observado; observa el repo primero con raptor repo add
mcp.refused-agent = rechazado: solo el desarrollador puede decidir qué repos usan los agentes por el MCP, no un agente ni un proceso lanzado por él
mcp.list-empty = ningún repo está habilitado para el MCP; habilita uno con raptor mcp enable
mcp.retired-from-allowlist = {path} también salió de la allowlist del MCP
