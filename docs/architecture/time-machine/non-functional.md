## Security NFRs

> **Modelo de amenaza**: el de motor-local (proceso del mismo usuario no confiable, incluido un **agente comprometido por prompt injection**, OWASP LLM01 / MCP Top 10; repo o worktree hostil; otros usuarios locales), más dos factores propios: **la Time Machine escribe en el repo y guarda contenido del usuario en el perfil**, y el almacén y el oplog son manipulables por ese mismo usuario. Sin superficie de red. **Matriz EH**: aplican las filas 15 (credenciales → SEC-TMC-01, 06), 18 (acceso no autenticado a funciones de administración → SEC-TMC-03, 15) y 19 (dependencias → SEC-07 de motor-local). Las filas 1-14, 16 y 17 (móvil, API web, TLS, cabeceras, caché, formularios) no aplican: no hay red ni interfaz web.
>
> **Alcance de la confirmación**: protege frente a agentes confundidos, **no** es una frontera frente a un proceso del mismo usuario que se desacopla de su árbol. Ese residuo se acepta en ADR-TMC-005 y lo compensa el snapshot previo de cada operación: un agente comprometido ya puede hacer `git reset --hard` sin GitRaptor.
