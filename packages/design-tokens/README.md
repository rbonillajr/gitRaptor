# @gitraptor/tokens

Design tokens de GitRaptor en formato [DTCG](https://www.designtokens.org/), según el [design system v0](../../docs/design-system/README.md).

- `tokens/*.json`: primitivos y semánticos (pendiente: paleta completa y `accent.default`).
- `pnpm nx build @gitraptor/tokens`: genera `build/` con Style Dictionary.

Pendiente: el formato que genera el módulo Rust de `crates/theme`.
